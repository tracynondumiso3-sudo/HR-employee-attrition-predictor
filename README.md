# HR Employee Attrition Predictor

End-to-end Machine Learning and People Analytics project in Python to predict employee turnover risk and evaluate key drivers of workplace attrition.

### Project Overview
This project predicts which employees are likely to leave the company using HR data. It helps HR teams take proactive action to retain talent.

### What I Did
- Cleaned and explored HR dataset (1,470 employees)
- Analyzed attrition patterns
- Built a Random Forest Classifier
- Found key drivers: MonthlyIncome, Age, YearsAtCompany, JobSatisfaction, WorkLifeBalance

### Tech Stack
Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

### Results
Achieved ~87% accuracy in predicting employee attrition
Key insight: Lower income + lower job satisfaction = higher risk of leaving

### How to Run
1. Open `HR Attrition_ prediction.ipynb` in Jupyter Notebook or Google Colab
2. Run all cells
